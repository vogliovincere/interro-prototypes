UI / UX Prototypes

Purpose-Built Platform for High Dollar, Multi-Party Transactions

Paying a Capital Call →

Investor-facing flow for sending money to Interro's U.S. account. Adapts wire details to the payment route, then — for international wires — asks which country the payer's own bank is in and relabels every field in that bank's own vocabulary, surfacing local requirements like Japan's balance-of-payments code or Brazil's contrato de câmbio.

3 screens · 40 jurisdictions

Receiving a Distribution →

The mirror image: collecting a recipient's bank details so Interro can wire money out. The field set itself changes by country — IBAN for Germany, ABA and account type for the U.S., BSB for Australia, IFSC for India, CLABE for Mexico, CPF/CNPJ for Brazil — with format validation on each.

4 screens · 40 jurisdictions
Prototypes contain fabricated demo data — not live payment instructions. Field requirements are drawn from International Wire Address Formats v2; see that report for sourcing and for the requirements flagged as unverified.
